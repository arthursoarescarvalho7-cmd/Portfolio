# Portfólio Pessoal

Este repositório contém o código-fonte do meu portfólio pessoal, desenvolvido para apresentar meus projetos, experiências profissionais e habilidades na área de desenvolvimento. O objetivo principal deste projeto é servir como um cartão de visitas digital interativo e de alto desempenho para recrutadores, clientes e parceiros.

## 1. Sobre o Projeto
O portfólio foi desenhado para ser uma vitrine clara e direta do meu perfil profissional. Ele destaca:
- **Apresentação Pessoal:** Seção dedicada a introduzir quem sou, minha paixão por tecnologia e meus principais objetivos de carreira.
- **Projetos:** Uma vitrine interativa com os principais trabalhos realizados, contendo descrições e links para os repositórios ou demonstrações.
- **Experiência Profissional:** Linha do tempo ou listagem detalhada das minhas atuações no mercado de trabalho.
- **Contato:** Canais diretos de comunicação (e-mail, redes sociais e formulários).

## 2. Tecnologias e Linguagens Utilizadas
A escolha das tecnologias foi feita visando a performance, a responsividade e a facilidade de manutenção:
- **HTML5:** Utilizado para estruturar semanticamente todo o conteúdo da página, garantindo acessibilidade e otimização para motores de busca (SEO).
- **CSS3:** Empregado para estilizar o layout, utilizando técnicas modernas de design responsivo para assegurar uma ótima experiência de visualização tanto em dispositivos móveis quanto em desktops.
- **JavaScript (Vanilla):** Responsável por toda a interatividade dinâmica do site (como manipulação do DOM, animações e validação de formulários), sem o peso de frameworks complexos desnecessários para esta escala de projeto.

## 3. Dependências e Bibliotecas
Para manter o projeto leve e de carregamento rápido, o uso de bibliotecas externas foi estritamente controlado:
- **Ícones e Assets Visuais:** Utilização de recursos otimizados (como imagens em PNG e ícones customizados) para compor a identidade visual sem comprometer a performance de carregamento.
- *Nota sobre dependências:* O projeto não faz uso de gerenciadores de pacotes pesados ou frameworks externos (como React ou Vue), sendo construído nativamente com tecnologias web fundamentais para garantir máxima compatibilidade e velocidade.

## 4. Como Executar o Projeto Localmente
Para testar e visualizar o projeto na sua máquina, siga os passos abaixo:

1. **Clone o repositório:**
   ```bash
   git clone <url-do-repositorio>
   ```
2. **Navegue até a pasta do projeto:**
   ```bash
   cd portfolio
   ```
3. **Abra o arquivo principal:**
   Abra o arquivo `index.html` (ou o arquivo de entrada correspondente) diretamente no seu navegador de preferência, ou utilize uma extensão como o *Live Server* no Visual Studio Code para uma melhor experiência de desenvolvimento.
